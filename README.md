# Hospital Management System

## About the Project
The Hospital Management System is a console-based application developed in C language. It is designed to manage basic hospital operations, including patient records, doctor information, appointments, medical histories, emergency cases, and billing.

## Features
- **Patient Management:** Register, edit, delete, view, and search patient records.
- **Doctor Management:** Add, edit, and view doctor profiles.
- **Appointment Management:** Book, cancel, and view appointments.
- **Medical History:** Add and view patients' medical histories.
- **Emergency Queue:** Manage emergency patients according to priority.
- **Billing System:** Generate, view, and update payment status of bills.
- **Searching and Sorting:** Search patient records and sort doctor information.
- **File Handling:** Save and load hospital data using a file.
- **Role-Based Access:** Separate menus for Admin, Doctor, and Reception.

4. Follow the menu options displayed on the screen.
